# 원본 · 시안

**여기 있는 파일은 배포에 포함되지 않는다.** `public/` 바깥이라 빌드가 건드리지 않는다.
웹에 나가는 그림은 `public/images/` 에 둔다.

| 파일 | 무엇 |
|---|---|
| `Login-시안.png` | 로그인 화면 시안 (화면을 이 모양으로 맞췄다) |
| `LoginPage-원본.png` | 로그인 히어로 사진 원본 PNG. 배포용은 `public/images/LoginPage.jpg` |
| `game-assets-원본.png` | 요리사 · 음식 에셋 시트 한 장. 잘라낸 조각은 `public/images/game/` |
| `game-cards-원본.png` | 3D 일러스트 4종(배너 · 월드컵 · 밸런스 · 돌림판). 사분면으로 나눠 잘랐다 |

## 왜 나눠 두나

`public/` 안의 파일은 쓰든 안 쓰든 **전부 `dist/` 로 복사된다.** 원본을 거기 두면
아무도 안 보는 2~3MB 짜리 파일이 사용자에게 같이 내려간다. 그렇다고 지우면 다시
자르거나 품질을 바꿀 때 원본이 없다. 그래서 원본은 여기, 쓰는 것만 `public/` 에 둔다.
