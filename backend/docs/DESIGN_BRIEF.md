# 뭐먹지? — 디자인 브리프

이미지 생성 AI나 디자이너에게 전달하기 위한 문서.
아래 내용을 통째로 복사해서 쓰면 된다.

> **확정 시안**: `docs/design/dashboard.png` (2026-08-17)
> 프론트엔드는 이 시안대로 구현되어 있다. 아래 색상·레이아웃은 시안 기준이다.

---

## 1. 서비스 한 줄 정의

**"오늘 뭐 먹지?"를 대신 정해주는 AI 음식 추천 서비스.**

날씨·예산·못 먹는 재료를 반영해 AI가 음식과 레시피를 만들어주고,
쇼핑 API로 재료 최저가까지 알려준다. 마음에 든 레시피는 기록으로 남기고
커뮤니티에 공유할 수 있다.

## 2. 사용자와 톤

- **주 사용자**: 20~30대 자취생, 직장인. 매일 "뭐 먹지"를 고민하는 사람
- **상황**: 퇴근길 지하철에서 폰으로, 또는 집에서 저녁 준비하며
- **톤앤매너**: 따뜻하고 담백함. 화려하지 않고 정보가 잘 읽히는 쪽.
  배달앱처럼 자극적인 사진 위주가 아니라, 레시피 노트에 가까운 정돈된 느낌
- **피해야 할 것**: 형광색, 과한 그라데이션, 3D 일러스트, 지나치게 둥근 만화풍

## 3. 디자인 시스템 (실제 코드에 적용된 값)

### 색상

| 용도 | HEX | 설명 |
|---|---|---|
| 배경 | `#f6f5f3` | 아주 옅은 웜 그레이. 순백이 아님 |
| 카드/표면 | `#ffffff` | 흰색 |
| 살구색 면 | `#fdf1e9` | 히어로·안내 카드 배경 |
| 테두리 | `#eae7e2` | 연한 베이지 그레이 |
| 본문 텍스트 | `#221f1c` | 거의 검정이지만 따뜻한 톤 |
| 보조 텍스트 | `#7b756d` | 회갈색 |
| **강조색** | **`#e8481c`** | **선명한 주황. 브랜드 컬러** |
| 강조 연한 배경 | `#fdece5` | 선택된 칩·아바타 배경 |
| 좋아요 하트 | `#e03131` | 붉은색 |
| 성공 / 경고 / 오류 | `#2f8a5b` / `#c9821a` / `#c0392b` | |

전체적으로 **웜 뉴트럴 팔레트**다. 차가운 파랑·회색 계열은 쓰지 않는다.
강조색은 버튼·활성 메뉴·링크·가격 표시에만 절제해서 쓴다.
활성 사이드바 메뉴는 강조색으로 **꽉 채우고 글자는 흰색**이다.

### 타이포그래피

- 서체: **Pretendard** (한글 산세리프)
- 페이지 제목 22px / 섹션 제목 17~18px / 본문 14~15px / 보조 13px
- 줄간격 1.6

### 형태

- 카드 모서리: 10px (모바일 12px)
- 버튼 모서리: 8px
- 태그·칩: 완전 둥근 형태 (999px)
- 그림자를 거의 쓰지 않는다. **1px 테두리로 구분**하는 것이 이 디자인의 특징
- 카드 안쪽 여백 20px (모바일 16px)

## 4. 하이브리드 레이아웃 (중요)

같은 화면이 폭에 따라 두 모드로 바뀐다.

### 웹 모드 (1024px 이상)

```
┌──────────┬──────────────────────────────────────────────┐
│ 🍚 뭐먹지? │  [ 검색어를 입력하세요…      🔍 ]  🔔 (홍)홍길동님⌄│
│          ├──────────────────────────────────────────────┤
│ ■ 홈      │ ┌──────┬───────────────┐ ┌─────────────────┐│
│   오늘뭐먹지│ │ 날씨  │ 오늘 뭐 먹지? ✨│ │ 좋아요 받은 레시피 ││
│   예산맞춤 │ └──────┴───────────────┘ │ [날짜]~[날짜][검색]││
│   못먹는재료│  오늘의 추천 레시피  더보기›│  ▢ 바삭한 김치전  ›││
│ ────────  │ ┌────┐┌────┐┌────┐      │  ▢ 두루치기      ›││
│   History │ │카드││카드││카드│      │                  ││
│   좋아요   │ └────┘└────┘└────┘      └─────────────────┘│
│   커뮤니티 │  최근 기록                ┌─────────────────┐│
│          │ ┌──────────────────────┐ │💡 AI 추천은 참고용││
│          │ │ 날짜│음식│레시피│재료비│ └─────────────────┘│
└──────────┴──────────────────────────────────────────────┘
  260px          본문 좌측(가변)              우측 380px
```

- 좌측 사이드바 고정 260px, 활성 메뉴는 **주황 배경 + 흰 글자**
- 상단 검색바는 **완전히 둥근 알약 모양**, 우측에 알림 벨(빨간 점) + 아바타
- 본문은 좌우 2단. 우측은 380px 고정

### 앱 모드 (1023px 이하)

```
┌─────────────────────┐
│ 🍚 뭐먹지?    🔔 (홍) │ ← 앱바, 스크롤해도 고정
│ [ 검색…        🔍 ] │
├─────────────────────┤
│  날씨 카드            │
│  오늘 뭐 먹지? (히어로) │
│  추천 카드 ▶ 가로 스크롤│
│  최근 기록            │
│  좋아요 받은 레시피    │
│  💡 안내              │
├─────────────────────┤
│ 🏠   ✨   🤍   🕐  👤 │ ← 하단 탭 58px, 고정
│ 홈  추천 좋아요 History MY│   활성 탭만 주황색
└─────────────────────┘
```

- 사이드바가 사라지고 하단 탭이 그 역할을 한다. 상단바에 로고가 추가된다
- 2단이 1단으로 합쳐지고, 추천 카드는 **가로 스크롤**로 바뀐다
- 하단 탭의 활성 항목만 컬러 아이콘 + 주황 글자, 나머지는 회색
- 아이폰 노치·홈 인디케이터 영역을 피하도록 안전 여백 적용

## 5. 화면별 구성

### ① 홈 (대시보드) — 가장 중요한 화면

접속하면 바로 이 화면이 뜬다. 별도 랜딩 페이지 없음.

세로로 4개 블록이 쌓인다.

1. **날씨 카드** — 좌측에 큰 이모지 아이콘(❄️/☀️/🌧️), 우측에 `3°` 큰 숫자와
   "눈", 아래 작은 글씨로 "서울 · 체감 -1° · 습도 62%"
2. **히어로 영역** — 가운데 정렬. 큰 제목 **"오늘 뭐 먹지?"**,
   아래 설명 한 줄, 그 아래 **검색 입력창 + "레시피 찾기" 버튼**
   (입력창 placeholder: "먹고 싶은 음식을 입력해보세요 (예: 김치찌개)")
3. **오늘 날씨 추천 (예산 필터 있음)**
   - 섹션 제목 아래에 **예산 입력 바**가 있다
     - 왼쪽에 둥근 입력칸 `[  8000 ] 원 이내`, 우측에 "초기화" 링크
     - 그 아래 둥근 칩 4개: `5천원` `8천원` `1만원` `1.5만원`
       (선택된 칩만 테라코타 테두리 + 연한 주황 배경)
     - 그 아래 회색 안내문 "8,000원 이내 2건"
   - 음식 카드 목록. 웹은 가로 3열, 모바일은 세로 1열
   - 카드 내용: 음식 이름(굵게) + 우측에 가격 `8,500원`(테라코타색),
     그 아래 추천 이유 2줄, 태그 칩들(`⏱ 25분` `난이도 쉬움` `#국물` `#한식`),
     맨 아래 "레시피 보기" 작은 버튼
4. **좋아요 받은 레시피 (기간 검색 있음)**
   - 섹션 제목 아래에 **기간 필터 바**
     - 왼쪽에 둥근 버튼 3개: `최근 7일` `최근 30일` `최근 90일`
       (기본값은 최근 30일이 선택된 상태)
     - 오른쪽에 날짜 입력 두 칸과 물결표 `2026-07-19 ~ 2026-08-17`
     - 모바일에서는 버튼 줄과 날짜 줄이 위아래로 나뉨
   - 목록 각 줄: `♥ 34`(테라코타) | **김치찌개** · 돼지고기 김치찌개 |
     우측에 회색으로 `집밥러 · 8,500원 · 2026.08.16`

**예시 데이터**: 콩나물국밥(4,200원) / 들깨 수제비(6,200원) / 김치찌개(8,500원) /
순두부찌개(9,800원) / 닭갈비(12,000원) / 소고기 미역국(15,400원)

### ② 레시피 상세

1. 상단에 "← 홈으로" 링크
2. **레시피 카드** — 음식명 `김치찌개`(22px), 아래 `돼지고기 김치찌개`,
   우측에 **"재료비 8,500원 ~ 13,050원"**
   (앞의 최저가는 테라코타 굵게, 뒤의 최고가는 회색 보통 굵기)
   - 칩 3개: `⏱ 25분` `2인분` `난이도 쉬움`
   - **재료** — 이름과 수량이 좌우로 나뉜 목록 (돼지고기 앞다리살 · 200g)
   - **만드는 법** — 번호 매긴 목록 4단계
   - **대체 재료** — "돼지고기 → 참치캔 · 더 간편하게 만들 수 있습니다"
3. **재료 가격 비교 표** — 3열: `재료` / `최저가` / `최고가`
   - 가격 칸은 2줄 구성. 윗줄에 금액, 아랫줄에 작은 회색 글씨로 판매처
     ```
     3,980원          5,200원
     쿠팡             알리익스프레스
     ```
   - 최저가 금액은 테라코타색 + 링크, 최고가는 회색
   - 마지막 줄에 굵은 구분선과 **합계** (8,500원 ~ 13,050원)
   - 표 아래 회색 주의문 "네이버쇼핑 · 쿠팡 · 알리익스프레스에서 조회한
     값입니다. 배송비는 포함되지 않으며..."
4. **"이걸로 먹을래요"** 큰 버튼 (모바일은 폭 100%)

### ③ History (내 기록)

- 제목 옆에 "총 3건 · 누적 26,700원"
- 목록 각 줄: `2026.08.16` | **김치찌개** · 돼지고기 김치찌개 | `8,500원` | ▼
- 줄을 누르면 아래로 펼쳐지며 레시피 전체가 보인다 (아코디언)

### ④ 커뮤니티 목록

- 상단에 제목 + 우측 "글쓰기" 버튼(테라코타)
- 검색 입력창
- 게시글 카드 3장. 각 카드: 제목(16px) → 본문 미리보기 2줄(회색) →
  하단에 음식 태그 칩, 작성자, 날짜, 우측 끝에 `♥ 12 · 💬 2 · 조회 128`

### ⑤ 게시글 상세

- 제목(22px) → 작성자·날짜·조회수·음식 태그 → 구분선 → 본문
- 하단에 둥근 **♥ 12** 좋아요 버튼 (누르면 테라코타 배경으로 채워짐)
- 그 아래 댓글 카드: "댓글 2" + 댓글 목록 + 입력 textarea + "등록" 버튼

### ⑥ MyPage

- **내 정보** 카드 — 닉네임 / 이메일 / 가입일 (라벨-값 2열)
- **못 먹는 재료** 카드
  - 입력창 + 드롭다운(싫어함/알레르기) + "추가" 버튼
  - 등록된 재료가 **둥근 칩**으로 나열됨
    - 알레르기 = 붉은 테두리 + 연한 붉은 배경 (`땅콩`)
    - 싫어함 = 황토색 테두리 + 연한 노란 배경 (`오이` `고수`)
  - 각 칩 우측에 작은 ✕ 삭제 버튼

### ⑦ 로그인 / 회원가입

- 최대 폭 420px, 가운데 정렬된 카드
- 라벨이 입력칸 위에 있는 세로 폼
- 전체 폭 테라코타 버튼
- 하단에 "비밀번호를 잊으셨나요?" / "아직 계정이 없으신가요? 회원가입" 링크
- 모바일에서는 카드 테두리가 사라지고 화면에 꽉 참

### ⑧ 비밀번호 재설정

- 상단에 **3단계 진행 표시** — 가로로 3등분된 굵은 선,
  현재 단계만 테라코타색 (`1. 이메일 확인` `2. 인증번호 입력` `3. 새 비밀번호`)
- 단계별로 폼이 바뀜. 2단계는 6자리 숫자 입력칸

## 6. 이미지 생성 AI에게 요청할 때 붙일 문장

> 한국어 모바일 웹앱 UI 목업. 따뜻한 아이보리 배경(#faf9f7)에 흰색 카드,
> 1px 연한 베이지 테두리(#e5e2dd)로 구분. 강조색은 테라코타 오렌지(#d1603d).
> 그림자 거의 없이 평평하고 정돈된 스타일. Pretendard 한글 산세리프.
> 카드 모서리 10px, 태그는 완전히 둥근 알약 형태.
> 화려하지 않고 정보 위주의 담백한 레시피 앱 느낌.

## 7. 참고할 만한 서비스

- **만개의레시피 / 우리의식탁** — 레시피 정보 구조
- **토스** — 정보 위계와 여백 처리 (색감은 다름)
- **배달의민족** — 은 참고하지 않는다. 너무 자극적이고 사진 중심
